Get started

1

Install awareness

Run the install script. It places the awareness binary in ~/.awareness/bin and adds it to your PATH.

2

Get an OpenRouter API key

Sign up at openrouter.ai/keys. Free credits are available to get started.

3

Run awareness

Launch awareness from any project directory. The onboarding flow will prompt you to connect OpenRouter, then you're ready to build.
